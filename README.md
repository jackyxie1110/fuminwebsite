# 富民粥品 Fumin Congee — 靜態品牌網站

富民粥品的第一版單頁品牌網站，以香港海港、水上生活、清晨爐火與街坊人情為敘事主線。網站提供繁體中文、簡體中文及英文，並採用純 HTML、CSS 和少量原生 JavaScript，不需要安裝套件、建置工具、後端或資料庫。

## 本機預覽

最簡單的方法是直接用瀏覽器開啟 `index.html`。如需模擬正式網站環境，可在此資料夾啟動任何靜態檔案伺服器，例如：

```bash
python3 -m http.server 8080
```

然後開啟 `http://localhost:8080`。

## 部署至 Cloudflare Pages

### 方式一：連接 Git 儲存庫

1. 把此資料夾推送到 GitHub 或 GitLab。
2. 在 Cloudflare 控制台前往 **Workers & Pages → Create → Pages → Connect to Git**。
3. 選取儲存庫後，設定：
   - Framework preset：`None`
   - Build command：留空
   - Build output directory：`/`（儲存庫根目錄）
4. 儲存並部署。

### 方式二：直接上傳

在 Cloudflare Pages 選擇 Direct Upload，把本資料夾中的 `index.html`、`styles.css`、`script.js` 一併上傳。日後購買網域後，可在該 Pages 專案的 **Custom domains** 加入。

## 上線前必須確認

網站目前刻意沒有虛構餐廳資料。請向餐廳確認後，更新三個語言版本的資料：

- 完整中英文地址的官方寫法
- 電話號碼是否仍然有效
- 最新營業時間、固定休息日或特別安排
- 六款展示粥品的堂食供應、正式配料與堂食售價
- 「生滾」與熬粥流程是否符合店內真實做法

以上內容集中在 `index.html`（繁體預設內容）及 `script.js`（三語翻譯）內。

## 建議由餐廳提供／拍攝的相片

現版本完全使用 CSS 抽象視覺，沒有外部相片，因此沒有第三方圖片版權風險。如日後要提升品牌真實感，建議以餐廳自有或委託拍攝的相片取代部分抽象畫面：

1. 清晨開爐、洗米或攪粥的手部特寫
2. 一碗艇仔粥的自然光近照
3. 生滾落料或粥面冒煙的瞬間
4. 店面外觀與佐敦街景
5. 店內熟客、伙計招呼或盛粥畫面（需取得人物同意）
6. 六款粥品的統一角度照片

拍攝時應保留橫向與直向構圖，並取得網站與商業宣傳用途的書面授權。不要直接下載 Google Maps、食評平台、社交媒體或新聞網站的圖片。

## 檔案結構

- `index.html`：語意化單頁內容與網站 metadata
- `styles.css`：三種尺寸的響應式設計、CSS 視覺及 reduced-motion 支援
- `script.js`：三語切換、瀏覽位置保留、手機選單及輕量進場效果
- `assets/images/`：網站使用的修飾後實拍圖片與招牌細節素材
